04 / PROJECT REFERENCE

TABLET EDITION

Terms for a changing canvas.

A shared reference for readers moving between portrait, landscape, and split-screen layouts. Each note opens with the browser's native popover behaviour; no custom script is required.

The tablet document is selected from 768 through 1099 CSS pixels. The router uses viewport width rather than attempting to identify a physical device.

  • Edition 03

    This is the current rebuild of the website. It begins the digital presentation again; it does not promise continuity with earlier manuscript drafts.

  • Reading room

    The part of the site reserved for published chapters. It is intentionally empty until the rewritten manuscript is supplied and approved.

  • Viewport

    The visible layout area inside the browser. The site uses its width to choose the mobile, tablet, or desktop homepage document.

  • Anchor link

    A link to a specific element on the same page. Its URL uses a fragment such as #reading, making a section easier to bookmark or share.

  • Progressive enhancement

    An approach that starts with meaningful document structure and adds optional presentation or behaviour. The glossary popovers here use native HTML.

  • Colophon

    A short record about an edition or publication. The project's About section acts as its digital colophon.

Why are there three homepage documents?

Each edition has its own HTML composition for a different viewport range. They share the same project identity and core information while arranging the content for the available space.

What can I read in the archive today?

No rewritten chapters have been published yet. The reading room remains empty rather than displaying invented titles, excerpts, or material from earlier drafts.

Do these notes describe story lore?

No. This is a guide to the website and its reading interface. It does not introduce characters, plot details, or unpublished story information.

09 / Questions Project information

A few things worth knowing.

Why is the reading room empty?

The novel is being rewritten from the first page. The archive will open when the new chapters are ready; older drafts will not be republished as placeholders.

Are these pages three different websites?

They are three independent homepage documents with separate compositions for phone, tablet, and desktop. They share the same project identity and core content.

How is the layout selected?

The site selects a composition from the current viewport width. It does not claim to detect the physical device. Resizing across a breakpoint can load a different page.

Do the reader controls affect chapters?

Not yet. The typography lab is a working preview. Its preferences are stored locally and demonstrate the controls intended for the future chapter reader.

Does the site require animation?

No. Motion is an enhancement. The content and navigation remain available if GSAP does not load or reduced motion is enabled.

Where are my reader preferences saved?

The preview uses local browser storage on this device. Clearing site data or using another browser may reset those settings.

Can I read the old version here?

No. This edition is a clean restart. Previous drafts and their story material are intentionally not carried into the new archive.

When will the first chapter be published?

There is no confirmed publication date. The archive status will change only after the author has supplied and approved the rewritten material.

12 / Device questions 10 ANSWERS

Before you settle in.

Does the tablet page lock orientation?

No. The page responds to viewport width and does not request an orientation lock.

Does split-screen work?

The layout should reflow, but actual tablet split-screen testing remains to be completed.

Can I use a hardware keyboard?

The page uses native controls and links. Keyboard and screen-reader QA should still be completed before launch.

Can I keep a section open after rotating?

The router preserves the current URL fragment when it selects the document for the new viewport width.

Why does routing use width?

Viewport width is a more reliable layout input than guessing the physical device type.

Can I read chapters now?

No rewritten chapters have been supplied for publication, so the archive remains intentionally empty.

Will the art move while I scroll?

The design avoids continuous scroll-scrubbed parallax. Motion is limited to selected enhancements.

What if remote fonts fail?

System fallbacks keep the text readable, although line breaks and proportions may change.

Is the site a full PWA?

A manifest is present, but a complete offline-capable PWA and service worker are not implemented.

How do I contact the project?

The contact page provides project information; a private inbox has not yet been configured.
