# Fate / Stay Last Time

An original, frontend-only web novel experience built with React, Vite and TypeScript.

## Development
- `npm install`
- `npm run dev`
- `npm run build`

Vercel is expected to build from the connected GitHub repository. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

This first visual demo uses original abstract CSS artwork and placeholder reading copy. Replace chapter text and lore with the author's canon material before treating it as published story content.
