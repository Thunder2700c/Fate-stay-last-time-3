Privacy notice.

DRAFT NOTICE / LAST REVIEWED: 26 NOVEMBER 2026

Read this before treating the page as a final policy.

This notice describes the current static website as inspected in the repository. Hosting providers and third-party services may process technical request information under their own policies. The project owner should review this document before launch and update it whenever the site adds a service that collects personal information.

1. Who this notice concerns

This notice applies to visitors of the Fate / Stay Last Time website at the production domain shown in the page's canonical URLs. It describes the current website features, not unrelated services or the GitHub platform itself.

2. Information entered by visitors

The current website does not provide an active contact-submission form, account registration, comment system, newsletter signup, payment flow, or chapter upload facility.

The contact page is informational. Its copy-address control copies a public repository URL when the visitor activates it. It does not transmit a message to the project owner.

Do not submit confidential, financial, health, identity, or account information through a public issue tracker or any future contact route unless the project publishes a suitable secure process and explains its purpose.

3. Reader preference storage

The reader preview can store a small set of display preferences in the browser's localStorage. These preferences include the preview tone, text size, line spacing, reading width, and font choice.

  • The preferences are stored in the visitor's browser, not in a project account.
  • The current implementation does not send these preference values to a project server.
  • Preferences are not synchronized between devices or browsers.
  • Clearing site data or browser storage may remove the saved values.
  • If browser storage is unavailable, controls may still work for the current page session without persistence.

4. Hosting and technical request data

The website is deployed as a static site on Vercel. When a browser requests a page or asset, the hosting platform and network infrastructure may process technical information such as the requested URL, request time, IP address, user-agent details, and diagnostic information. The exact information, retention period, and processing purposes are governed by the hosting provider's current documentation and policies.

This project does not control the hosting provider's operational logs. Consult the provider's own privacy information for details about its infrastructure and data handling.

5. Third-party resources

The current pages reference Google Fonts and the GSAP animation library through public content delivery services. A browser may contact those services to retrieve font files or JavaScript resources.

  • Google Fonts may receive a resource request when the page loads the selected typefaces.
  • jsDelivr may receive a request when the page loads GSAP or ScrollTrigger.
  • The site may continue to display its content with fallback fonts if remote fonts are unavailable.
  • GSAP is an enhancement; the page's core text and navigation should remain available without it.

These external providers operate under their own terms and privacy notices. Self-hosting resources may be considered as part of a future production review.

6. Cookies, analytics, and advertising

The inspected project code does not intentionally add an analytics platform, advertising pixel, user profiling system, or marketing cookie. This statement does not override cookies or technical storage that may be used by the hosting platform or by third-party resources.

If analytics, advertising, embedded media, or other tracking services are introduced, this notice must be revised before those services are enabled.

7. Children's privacy

The current website is a public novel-project site and does not intentionally request personal information from children. Because there is no active submission service, visitors should not send personal details through unrelated public channels.

8. Data security and retention

No project-side visitor account database or contact-message database is implemented in this static edition. Local reader preferences remain subject to the browser's storage controls. Hosting and third-party providers may have their own security and retention practices.

9. External links

The website may link to GitHub or other external websites. Once a visitor leaves this domain, the destination site's privacy practices apply. Review the destination's own notice before sharing information there.

10. Changes to this notice

This notice may change when the website gains new functionality, changes hosting, or begins collecting information. The review date at the top should be updated when the contents are materially revised.

11. Contact and privacy requests

A private contact inbox has not yet been configured. The contact page identifies the current public project route, but a public repository issue is not a private channel for sensitive privacy requests.

Important limitation

This is a project-specific draft based on the current implementation, not legal advice or a guarantee that every infrastructure provider handles data in the same way. Obtain an appropriate legal review for the actual operator, jurisdiction, and launch configuration.
